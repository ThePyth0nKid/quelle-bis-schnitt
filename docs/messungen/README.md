# Eigene Messungen

Jede Zahl in diesem Repo hat eine Quelle. Ist die Quelle keine öffentliche Veröffentlichung, sondern eine eigene Messung,
steht hier, wie gemessen wurde. Die Skills verweisen dann so darauf:

> eigene Messung, n = 63 Kanäle, Methode in `docs/messungen/hook-studie.md`

## Pflichtangaben je Messung

Jede Datei in diesem Ordner beantwortet dieselben Fragen:

| Angabe | Inhalt |
|---|---|
| Frage | Was sollte die Messung zeigen? |
| Stichprobe | Was wurde gemessen, wie viele Einheiten (n), wie ausgewählt? |
| Zeitraum | Wann wurde gemessen? |
| Verfahren | Schritte, Werkzeuge, Schwellen. So genau, dass jemand anders es wiederholen kann. |
| Ergebnis | Die Zahlen, die in den Skills stehen, mit Streuung, wenn es eine gibt. |
| Grenzen | Was die Messung nicht zeigt (Korrelation statt Ursache, kleine Stichprobe, eine Plattform …). |
| Rohdaten | Ob und wo sie liegen. Rohdaten mit Bezug auf reale Konten oder Personen werden nicht veröffentlicht. |

Eine Messung ohne diese Angaben ist eine Behauptung und gehört nicht in einen Skill.
